A short poem about the last lighthouse keeper's last night, written by a program, entered in make.fun's "The poem about stopping" bounty.

## Run it

```sh
python3 main.py
```

It writes the entry text to `entry.txt` in the directory named by
`MAKEFUN_OUTPUT_DIR` (default `/output`).
